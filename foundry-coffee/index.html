The craft

We roast it like it matters. Because it does.

Every batch is roasted by hand and logged by curve — we taste, adjust, and taste again until each origin sings. Small batches mean it's always fresh, never sitting in a warehouse losing its soul.

The story

Started in a garage. Still roasting like it.

Foundry began with one used roaster, a notebook, and a stubborn belief that coffee should taste like where it's from. Years later we've grown — but every bag still gets the same obsessive attention as that very first batch.
